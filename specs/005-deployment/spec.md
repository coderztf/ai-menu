# 005 Linux 一键部署

服务器项目默认位于 /opt/ai-menu，执行 bash scripts/start.sh 后先获取 origin/main 并快进更新，再安装依赖、执行数据库增量迁移、后台启动。工作区有已跟踪改动或分支无法快进时停止。更新或迁移失败时不启动新服务。

迁移按文件名排序，每个迁移在独立事务中执行，成功记录文件名和 SHA-256。已执行脚本内容变化时终止。后续数据库结构变更必须新增 migrations/ 中的递增编号 SQL，并同步规格与验收；脚本不得自行包含事务控制。新数据库执行基线，已有 user_version=1 的数据库经基线表字段核对后接管。迁移前备份数据库。

后台采用单个 Uvicorn worker，日志按 Asia/Shanghai 自然日写入 /opt/ai-menu/logs/YYYY-MM-DD.log，跨午夜自动切换。后台 PID 文件用于重复启动时替换旧进程，端口默认 8000，监听默认 0.0.0.0。需要 Linux、Git、Python 3.11+ 和可用网络。配置及数据库留在服务器。
