# 006 删除库存食材

库存卡片提供删除按钮，弹窗确认后从库存与食材选择列表移除受限食材。采用归档保留字典及历史引用，同时把库存置为用完并清理备注和优先标记。常备食材不能删除。版本冲突拒绝提交，重复提交同一请求返回原结果。再次按原名称录入可恢复原食材。已做菜单历史保留，未做菜单因库存版本变化重新校验。

验收覆盖删除后列表隐藏、库存不可用于推荐、重复提交、版本冲突、常备保护以及再次录入恢复。增量迁移新增归档表。

删除入口样式调整：卡片内使用小号灰色文字“删除”，无边框及底色；仅悬停或键盘聚焦时增强提示。保留可访问名称和确认弹窗，手机端持续可见。验收文字入口采用独立样式且不影响其他按钮。

删除入口再次调整：每张食材卡片右上角显示小号 ×，无底色边框，固定 28×28 像素，不占食材详情的排列空间。为按钮提供“删除＋食材名”的可访问名称和悬停提示，保留确认弹窗。卡片右侧预留空间避免覆盖名称。更新 CSS 和 JS 的资源版本，刷新后加载一致的新界面。
